import java.util.List;
import java.util.ListIterator;

public class App2 {

	public static void main(String[] args) {
		List<Integer> list=List.of(11,2,5,3,9,12,7,8,10);

		ListIterator<Integer> it = list.listIterator(list.size());
		
		while(it.hasNext()) {
			Integer current = it.next();
			System.out.println(current);
		}
		System.out.println("............");
		
		while(it.hasPrevious()) {
			Integer x = it.previous();
			System.out.println(x);
		}
	}

}

## ✅ Java Collections: **List Interface**

### 📘 1. Introduction to List Interface

* The `List` interface is part of the Java Collections Framework.
* It allows **ordered** collection of elements (maintains insertion order).
* Allows **duplicates**.
* Elements can be accessed via **index**.

```java
List<String> names = new ArrayList<>();
names.add("Alice");
names.add("Bob");
System.out.println(names.get(0)); // Output: Alice
```

---

### 📘 2. Implementations of List

| Implementation | Characteristics                                  |
| -------------- | ------------------------------------------------ |
| `ArrayList`    | Fast random access, slow insert/delete in middle |
| `LinkedList`   | Good for frequent insert/delete, slower access   |
| `Vector`       | Synchronized, thread-safe, legacy class          |

---

### 📘 3. Common List Methods

| Method                 | Description                  |
| ---------------------- | ---------------------------- |
| `add(element)`         | Adds to end                  |
| `add(index, element)`  | Adds at index                |
| `remove(index)`        | Removes by index             |
| `remove(Object)`       | Removes first occurrence     |
| `get(index)`           | Get element                  |
| `set(index, element)`  | Replace element              |
| `contains(element)`    | Checks if exists             |
| `indexOf(element)`     | Returns index of first match |
| `lastIndexOf(element)` | Returns index of last match  |
| `size()`               | Number of elements           |
| `clear()`              | Removes all elements         |
| `isEmpty()`            | Checks if list is empty      |

---

### 📘 4. Iterating a List

```java
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

for (String name : list) {
    System.out.println(name);
}

list.forEach(System.out::println);

Iterator<String> it = list.iterator();
while(it.hasNext()) {
    System.out.println(it.next());
}
```

---

### 📘 5. Sorting and Searching

* `Collections.sort(list)`
* `Collections.reverse(list)`
* `Collections.binarySearch(list, element)` – **list must be sorted**

---

### 📘 6. Converting List to Array and Vice Versa

```java
List<String> list = Arrays.asList("A", "B", "C");
String[] array = list.toArray(new String[0]);
List<String> newList = Arrays.asList(array);
```

---

### 📘 7. List vs Set vs Map (Quick Compare)

| Feature         | List       | Set            | Map                         |
| --------------- | ---------- | -------------- | --------------------------- |
| Duplicates      | Allowed    | Not allowed    | Keys not allowed duplicates |
| Order           | Maintained | Not guaranteed | Key-value pair              |
| Access by index | Yes        | No             | No                          |
