Cascading Stylesheet		(CSS)

is very useful for styling HTML pages.
We can do any styling in HTML language itself. But when we want consistent styling across multiple pages and also, quick change in the style at runtime, we rely on CSS.

CSS has its own syntax.

all that we do in css is styling, effects, animation

portion 1 is the selector
portion 2 is the styles
	inside portion 2, key-value pair then a semicolon

ex:

p
{
	text-align:center
}



there can be 3 ways, the css are used in HTML

1) in-line
2) internal/ embedded
3) external

in-line
-------
in the line of a HTML element, we specify styles.
that style applies only that element on that line
	in-line wins

it is achieved using "style" attribute.

<p style="">
