# 🏏 Functions in Python

---

## 🔹 1. What is a Function?

* A **function** is a reusable block of code that performs a specific task.
* Instead of writing the same code again and again, you put it inside a function and just call it whenever needed.
* Think of it like a **batsman** in IPL: once trained (defined), you can send him to bat (call) multiple times.

---

## 🔹 2. Syntax of a Function

```python
def function_name(parameters):
    # code block
    return value
```

* `def` → keyword to define a function
* `function_name` → your chosen name (should be meaningful)
* `parameters` → inputs (optional)
* `return` → sends output back (optional)

---

## 🔹 3. Example 1: Function Without Parameters

```python
def cheer_team():
    print("Ee Sala Cup Namde! 🔥")

cheer_team()  # calling the function
cheer_team()
```

👉 Output:

```
Ee Sala Cup Namde! 🔥
Ee Sala Cup Namde! 🔥
```

---

## 🔹 4. Example 2: Function With Parameters

```python
def greet_player(name):
    print(f"Welcome {name} to RCB 🏏")

greet_player("Kohli")
greet_player("Maxwell")
```

👉 Output:

```
Welcome Kohli to RCB 🏏
Welcome Maxwell to RCB 🏏
```

---

## 🔹 5. Example 3: Function With Return Value

```python
def add_runs(runs1, runs2):
    return runs1 + runs2

total = add_runs(45, 67)
print("Total Runs:", total)
```

👉 Output:

```
Total Runs: 112
```

---

## 🔹 6. Example 4: Default Parameters

```python
def player_status(name="Unknown", runs=0):
    print(f"{name} scored {runs} runs")

player_status("Faf", 72)
player_status("Siraj")  # uses default runs=0
```

---

## 🔹 7. Example 5: Return Multiple Values

```python
def player_stats(runs, balls):
    strike_rate = (runs / balls) * 100
    return runs, balls, strike_rate

stats = player_stats(50, 30)
print("Runs:", stats[0], "Balls:", stats[1], "Strike Rate:", stats[2])
```

---

## 🔹 8. Why Functions? (Benefits)

✔ Reusable code
✔ Cleaner and organized programs
✔ Easier to test/debug
✔ Can divide big problems into smaller tasks

# 🏏 Python Error Handling

---

## 🔹 1. What is an Error?

* Errors are problems that stop your program from running.
* Example: dividing by zero, spelling mistakes in code, wrong input type.
* Python shows errors called **Exceptions**.

👉 Types of errors:

1. **Syntax Errors** → mistakes in writing Python code.
2. **Runtime Errors (Exceptions)** → errors that occur while program is running.

---

## 🔹 2. Handling Errors with `try-except`

```python
try:
    runs = int(input("Enter runs: "))
    print("Runs doubled:", runs * 2)
except ValueError:
    print("Invalid input! Please enter a number.")
```

👉 Analogy: In IPL, if a bowler bowls a **no-ball**, the game doesn’t stop — it gives a **free hit**. Similarly, `try-except` ensures the program doesn’t crash.

---

## 🔹 3. Catching Multiple Exceptions

```python
try:
    score = int(input("Enter score: "))
    balls = int(input("Enter balls: "))
    strike_rate = (score / balls) * 100
    print("Strike Rate:", strike_rate)
except ValueError:
    print("Invalid input! Enter numbers only.")
except ZeroDivisionError:
    print("Balls faced cannot be zero!")
```

---

## 🔹 4. Using `else` and `finally`

```python
try:
    runs = int(input("Enter runs: "))
except ValueError:
    print("Invalid input!")
else:
    print("You entered:", runs)
finally:
    print("Match over! 🎉")
```

* `else` → runs if no error happens.
* `finally` → always runs, like closing ceremony after IPL final (happens no matter what).

# 📘 Chapter: Modules and Libraries

## 1. 🔹 What is a Module?

* A **module** is just a **Python file (`.py`) that contains code** (functions, variables, classes).
* You can **import** it into another file and reuse the code.
* Helps in **code organization** and avoids duplication.

**Example:**
📂 `rcb.py`

```python
def cheer():
    print("RCB! RCB! RCB!")
```

📂 `main.py`

```python
import rcb

rcb.cheer()  # Output: RCB! RCB! RCB!
```

---

## 2. 🔹 Built-in Modules

Python comes with many modules pre-installed.
Examples:

* `math` → mathematical operations
* `random` → random numbers
* `datetime` → dates and time
* `os` → operating system functions

**Example:**

```python
import math
import random
from datetime import date

print(math.sqrt(49))        # 7.0
print(random.randint(1,6))  # dice roll
print(date.today())         # current date
```

---

## 3. 🔹 Installing External Libraries

* Python has a package manager called **pip**.
* Install packages from **PyPI (Python Package Index)**.

**Example:**

```bash
pip install requests
```

Use it:

```python

```

---

## 4. 🔹 Standard vs Third-Party Libraries

* **Standard libraries**: Come with Python (e.g., `os`, `math`, `json`).
* **Third-party libraries**: Installed via pip (e.g., `requests`, `pandas`, `flask`).

# 🏏 Object-Oriented Programming (OOP) in Python (Part 2)

---

## 1. 🔹 Polymorphism

📌 **Definition**: Polymorphism means “**many forms**.”
In OOP, it allows methods with the **same name** to behave **differently** depending on the object (class).

---

### Example 1: Method Overriding (we already saw)

```python
class Player:
    def role(self):
        print("Generic Player")

class Batsman(Player):
    def role(self):
        print("Batsman - Focused on scoring runs")

class Bowler(Player):
    def role(self):
        print("Bowler - Focused on taking wickets")

virat = Batsman()
siraj = Bowler()

for p in [virat, siraj]:
    p.role()
```

✅ Output:

```
Batsman - Focused on scoring runs
Bowler - Focused on taking wickets
```

👉 Same method name `role()`, different behaviors → **Polymorphism**.

---

### Example 2: Duck Typing (Python’s flavor of polymorphism)

In Python, if an object has a method, it doesn’t matter what class it belongs to.
"If it walks like a duck and quacks like a duck, it’s a duck." 🦆

```python
class Commentator:
    def speak(self):
        print("Commentator: Describes the match")

class Umpire:
    def speak(self):
        print("Umpire: Gives decisions")

def announce(person):
    person.speak()

announce(Commentator())
announce(Umpire())
```

✅ Output:

```
Commentator: Describes the match
Umpire: Gives decisions
```

---

### Example 3: Operator Overloading

Python allows overriding operators (like `+`, `*`, etc.) using **magic methods**.

```python
class Score:
    def __init__(self, runs):
        self.runs = runs
    
    def __add__(self, other):
        return Score(self.runs + other.runs)

    def __str__(self):
        return str(self.runs)

kohli = Score(82)
maxwell = Score(50)

total = kohli + maxwell
print("Total Score:", total)
```

✅ Output:

```
Total Score: 132
```

---

## 2. 🔹 Encapsulation

📌 **Definition**: Wrapping **data (attributes)** and **methods** into a single unit (class).

* Protect data using **access specifiers**.
* In Python, access control is not strict like Java, but we follow conventions:

| Type      | Convention | Example           |
| --------- | ---------- | ----------------- |
| Public    | No `_`     | `player.name`     |
| Protected | One `_`    | `player._age`     |
| Private   | Two `__`   | `player.__salary` |

---

### Example:

```python
class Player:
    def __init__(self, name, salary):
        self.name = name
        self.__salary = salary   # private attribute
    
    def get_salary(self):
        return self.__salary
    
    def set_salary(self, new_salary):
        if new_salary > 0:
            self.__salary = new_salary
        else:
            print("Invalid salary")

virat = Player("Virat Kohli", 1000000)

print(virat.get_salary())   # Access via getter
virat.set_salary(1200000)   # Update via setter
print(virat.get_salary())
```

## 3. 🔹 Abstraction

📌 **Definition**: Hiding implementation details and showing only the required functionality.
In Python, we use the `abc` module (Abstract Base Class).

---

### Example:

```python
from abc import ABC, abstractmethod

class Coach(ABC):
    @abstractmethod
    def train(self):
        pass

class BattingCoach(Coach):
    def train(self):
        print("Improving batting skills")

class BowlingCoach(Coach):
    def train(self):
        print("Improving bowling skills")

coach1 = BattingCoach()
coach2 = BowlingCoach()

coach1.train()
coach2.train()
```

✅ Output:

```
Improving batting skills
Improving bowling skills
```

## 4. 🔹 Special / Magic Methods

Python classes have many built-in **dunder methods** (double underscore).
Examples:

* `__init__` → constructor
* `__str__` → string representation
* `__len__` → length
* `__add__`, `__sub__`, etc. → operator overloading

---

### Example:

```python
class Team:
    def __init__(self, name, players):
        self.name = name
        self.players = players
    
    def __len__(self):
        return len(self.players)
    
    def __str__(self):
        return f"Team {self.name} with {len(self.players)} players"

rcb = Team("RCB", ["Virat", "Maxwell", "Siraj"])
print(len(rcb))   # calls __len__
print(rcb)        # calls __str__
```

✅ Output:

```
3
Team RCB with 3 players
```
