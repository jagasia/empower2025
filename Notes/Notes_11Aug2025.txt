## 1️⃣ **File**

**Task:**
Write a program to check if a directory named `reports` exists in your project folder.
If it does not exist, create it. Then, list all files inside the directory and print their **name**, **size (bytes)**, and **last modified date**.

**Hint:**

* Use `File` class to check existence, create directories, and get file metadata.
* Use `listFiles()` to iterate over files.


import java.io.File;
import java.io.IOException;
import java.text.SimpleDateFormat;
import java.util.Date;

public class Task1 {

	public static void main(String[] args) throws IOException {
		File dir=new File("d:\\jag");
		if(dir.exists()) {
			//display all files
			File[] files = dir.listFiles();
			SimpleDateFormat sdf=new SimpleDateFormat("dd-MMM-yyyy");
			for(File f:files) {
				if(f.isFile()) {
					String name = f.getName();
					long size = f.length();
					long lm = f.lastModified();
					
					System.out.printf("**%s**%d**%s**\n",name, size, sdf.format(new Date(lm)));
				}
			}
		}else {
			dir.createNewFile();	//create if not exists
		}
	}

}

## 4️⃣ **FileReader**

**Task:**
Write a program to read `story.txt` **character by character** and count the number of vowels in it.

**Hint:**

* Use `FileReader` to read characters directly (no byte conversion needed).
* Increment vowel count whenever you find `a, e, i, o, u` (case-insensitive).


import java.io.FileReader;
import java.io.IOException;

public class Task4 {

	public static void main(String[] args) throws IOException {
		FileReader fr=new FileReader("story.txt");
		int data='\0';
		int countVowel=0;
		while((data=fr.read())!=-1) {
			char c=(char) data;
			switch(c) {
			case 'a':
			case 'e':
			case 'i':
			case 'o':
			case 'u':
			case 'A':
			case 'E':
			case 'I':
			case 'O':
			case 'U':
				countVowel++;
			}
			
		}
		System.out.println(countVowel);
	}

}

## 7️⃣ **BufferedOutputStream**

**Task:**
Write a program that copies a file `source.pdf` to `copy.pdf` using `BufferedInputStream` and `BufferedOutputStream`.

**Hint:**

* Wrap both input and output streams with buffered versions.
* Read in chunks (e.g., `byte[1024]`) for better performance.

import java.io.BufferedInputStream;
import java.io.BufferedOutputStream;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class Task7 {

	public static void main(String[] args) throws IOException {
		BufferedInputStream bis=new BufferedInputStream(new FileInputStream("source.pdf"));
		BufferedOutputStream bos=new BufferedOutputStream(new FileOutputStream("copy.pdf"));
		
		byte []data=new byte[1024];
		while(true) {
			data=bis.readNBytes(1024);
			if(data==null) {
				break;
			}
			bos.write(data);
			bos.flush();
		}
		bos.close();
		bis.close();
		
		
	}

}

## **Task 1 – File**

```java
import java.io.File;
import java.io.IOException;
import java.text.SimpleDateFormat;
import java.util.Date;

public class Task1 {
    public static void main(String[] args) throws IOException {
        File dir = new File("reports"); // project folder "reports"
        if (!dir.exists()) {
            if (dir.mkdirs()) {
                System.out.println("Directory created: " + dir.getAbsolutePath());
            }
        }

        File[] files = dir.listFiles();
        if (files != null && files.length > 0) {
            SimpleDateFormat sdf = new SimpleDateFormat("dd-MMM-yyyy");
            for (File f : files) {
                if (f.isFile()) {
                    System.out.printf("%s\t%d bytes\t%s%n",
                            f.getName(), f.length(), sdf.format(new Date(f.lastModified())));
                }
            }
        } else {
            System.out.println("Directory is empty.");
        }
    }
}
```

synchronized block
-----------------
in a method, there may be lot of line,
a portion of code, we put inside the synchronized block,
so all threads simultaneously enter the method, proceed, 
	until a thread enters the sync block.
		once a thread enters sync block, all other threads will wait to enter
			one by one






public class NumberGenerator {
	
	public void generate() throws InterruptedException {
		String name=Thread.currentThread().getName();
		System.out.println(name+" Entered the generate method now...");
		
		for(int i=0;i<5;i++) {
			System.out.println(name+" ... "+i);
			Thread.sleep(1000);
		}
		
		synchronized (this) {
			System.out.println(name+" Entered the sync block now...");
			for(int i=100;i<110;i++) {
				System.out.println(Thread.currentThread().getName()+" : "+i);
				try {
					Thread.sleep(1000);
				} catch (InterruptedException e) {
					// TODO Auto-generated catch block
					e.printStackTrace();
				}
			}			
			System.out.println(name+" exited the sync bloc now...");
		}
		for(int i=0;i<35;i++) {
			System.out.println(name+" ... "+i);
			Thread.sleep(1000);
		}
		System.out.println(name+" exited the generate method now...");
	}
}

	}
