What is a wildcard (?) in generics?
A wildcard represents an unknown type in generics.

Useful when you don’t care about the exact type parameter, but still want to use the generic class/method safely.

Syntax:

? → Unknown type

? extends SomeClass → Upper-bounded wildcard

? super SomeClass → Lower-bounded wildcard

it is similar to SELECT statement in SQL
	SELECT is used to filter, sort, group by, etc on RELATIONS (tables)

	Stream API is used to do the same on COLLECTIONS


read only access to collections.	Every operation may return another stream










import java.util.Arrays;
import java.util.List;
import java.util.function.Consumer;
import java.util.function.Predicate;
import java.util.stream.Stream;
class MyPredicate implements Predicate<Integer>{
	@Override
	public boolean test(Integer t) {		
		return t%2!=0;
	}	
}
class MyConsumer implements Consumer<Integer>{
	@Override
	public void accept(Integer t) {
		System.out.println(t);	
	}
}
public class App {
	public static void main(String[] args) {
		List<Integer> marks=Arrays.asList(17,82,39,14,51,26,73,48,95,10);
		Stream<Integer> s1 = marks.stream();
		Stream<Integer> s2 = s1.filter(new MyPredicate());
		Stream<Integer> s3 = s2.sorted();
		
		s3.forEach(new MyConsumer());
				
	}
}

Complete notes for Stream API:-
=======================
Here’s a **roadmap-style summary** of what you should learn in the **Java Stream API** so you can move from beginner to advanced comfortably.

---

## **1. Basics of Stream API**

* **What is a Stream?** (vs Collection — stream is for processing, not storing data)
* **Creating Streams**:

  * From collections (`list.stream()` / `list.parallelStream()`)
  * From arrays (`Arrays.stream(arr)`)
  * Using `Stream.of()`
  * Infinite streams (`Stream.iterate()`, `Stream.generate()`)
* **Stream Pipeline Structure**:

  1. **Source** (collection, array, generator)
  2. **Intermediate operations** (transform/filter data)
  3. **Terminal operation** (produces result, ends the stream)

---

## **2. Intermediate Operations** (returns another Stream)

* **`filter(Predicate)`** → keep only matching elements
* **`map(Function)`** → transform each element
* **`flatMap(Function)`** → flatten nested structures (e.g., `List<List<T>>` → `List<T>`)
* **`distinct()`** → remove duplicates
* **`sorted()` / `sorted(Comparator)`** → sort data
* **`peek(Consumer)`** → debug/inspect without changing stream
* **`limit(n)`** / **`skip(n)`** → take or skip elements

---

## **3. Terminal Operations** (returns a result, ends the stream)

* **Iteration**: `forEach()`, `forEachOrdered()`
* **Reduction**:

  * `reduce(identity, accumulator)`
  * `reduce(accumulator)` (optional identity)
* **Collection**:

  * `collect(Collectors.toList())`
  * `collect(Collectors.toSet())`
  * `collect(Collectors.toMap())`
* **Counting & Matching**:

  * `count()`
  * `anyMatch()`, `allMatch()`, `noneMatch()`
* **Finding**:

  * `findFirst()`
  * `findAny()`
* **Min/Max**:

  * `min(Comparator)`
  * `max(Comparator)`

---

## **4. Collectors (java.util.stream.Collectors)**

* **Basic**:

  * `toList()`, `toSet()`, `toMap()`
  * `joining()`
* **Aggregation**:

  * `counting()`
  * `summingInt()`, `summingDouble()`, `averagingInt()`, `averagingDouble()`
* **Grouping & Partitioning**:

  * `groupingBy(classifier)`
  * `groupingBy(classifier, downstream collector)`
  * `partitioningBy(predicate)`
* **Reducing**:

  * `reducing(identity, mapper, accumulator)`

---

## **5. Primitive Streams**

* `IntStream`, `LongStream`, `DoubleStream`

  * Avoids boxing/unboxing overhead
  * Special methods like `sum()`, `average()`

---

## **6. Parallel Streams**

* Creating with `parallelStream()` or `stream().parallel()`
* When to use & pitfalls (thread-safety, ordering, overhead)

---

## **7. Advanced Concepts**

* Custom collectors (`Collector.of()`)
* Lazy evaluation (operations are not executed until terminal op)
* Short-circuiting (`limit()`, `findFirst()`, `anyMatch()`)

---

## **8. Common Patterns & Use Cases**

* Filtering and mapping
* Transforming data types
* Grouping and summarizing
* Finding top-N elements
* Flattening nested collections
* Joining strings from objects

---

```
        |
        |  Terminal Operation (triggers processing)
        |  ----------------------------------------
        |   collect(...)
        |   forEach(...)
        |   reduce(...)
        |   count()
        |
        v
[Final Result]   (List, Set, printed output, reduced value, etc.)
```

```java
    .filter(name -> name.startsWith("C"))         // Intermediate (lazy)
    .map(String::toUpperCase)                     // Intermediate (lazy)
    .toList();                                    // Terminal (processing starts)
```

import java.util.Arrays;

import java.util.Map;

    public static void main(String[] args) {

            new Product("Pen", "Stationery", 20.0),
            new Product("Pencil", "Stationery", 10.0),

        .collect(Collectors.groupingBy((t)->t.category, Collectors.summingDouble((t)->t.price)));;

        .filter((t)->t.getValue()>100)
