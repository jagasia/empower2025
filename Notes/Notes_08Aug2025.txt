Understand generics in java

What is a wildcard (?) in generics?
A wildcard represents an unknown type in generics.

Useful when you don’t care about the exact type parameter, but still want to use the generic class/method safely.

Syntax:

? → Unknown type

? extends SomeClass → Upper-bounded wildcard

? super SomeClass → Lower-bounded wildcard

Java 8 feature - Lambda

->


Lambda is used in java, to provide a quick implementation of functional interface.

What is functional interface?
	an interface that has only 1 abstract method 
		ex:
			Comparator
			Runnable
			Predicate
			

what is marker interface?
	an interface that has no abstract method.
		ex:
			Serializable





lets create our own functional interface now.




public interface Person {
	void speak();
}





public class App {

	public static void main(String[] args) {
		Person raja;
		
		raja=()->{	System.out.println("Mithun speaks");};
		raja.speak();
		
		//below is the anonymouos implementation that was followed before Java 1.8
		raja=new Person() {
			
			@Override
			public void speak() {
				// TODO Auto-generated method stub
				
			}
		};
	}

}

## **📝 Task 1 — Calculator with Lambda**

**Objective:** Implement a functional interface for basic arithmetic using a lambda expression.

### Requirements:

1. Create a **functional interface**:

```java
@FunctionalInterface
interface Operation {
    int perform(int a, int b);
}
```

@FunctionalInterface
public interface Operation {
	int perform(int a, int b);
}



2. In `main()`, create **two lambda expressions**:

   * One for addition
   * One for multiplication



public class AppReq1 {

	public static void main(String[] args) {
		Operation op1=(x,y)->x+y;
		Operation op2=(x,y)->x*y;
		System.out.println(op1.perform(10, 5));
		
		System.out.println(op2.perform(10, 5));
	}

}




3. Use them to:

   * Add `10` and `5` → print result
   * Multiply `10` and `5` → print result

**Expected Output:**

```
Addition: 15
Multiplication: 50
```

## **📝 Task 2 — Greeting Service**

**Objective:** Implement a functional interface to greet a person using a lambda expression.

### Requirements:

1. Create a **functional interface**:

```java
@FunctionalInterface
interface GreetService {
    void greet(String name);
}
```

2. In `main()`, create a **lambda** that:

   * Accepts a name
   * Prints `"Hello, <name>! Welcome to Lambda Expressions."`
3. Call the lambda for:

   * `"Alice"`
   * `"Bob"`

**Expected Output:**

```
Hello, Alice! Welcome to Lambda Expressions.
Hello, Bob! Welcome to Lambda Expressions.
```



public class AppTask2 {

	public static void main(String[] args) {
		GreetService gs=(name)->System.out.printf("Hello, %s! Welcome to Lambda Expressions.\n",name);
		
		gs.greet("Alice");
		gs.greet("Bob");
		
	}

}
