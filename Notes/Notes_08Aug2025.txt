What is a wildcard (?) in generics?
A wildcard represents an unknown type in generics.

Useful when you don’t care about the exact type parameter, but still want to use the generic class/method safely.

Syntax:

? → Unknown type

? extends SomeClass → Upper-bounded wildcard

? super SomeClass → Lower-bounded wildcard
