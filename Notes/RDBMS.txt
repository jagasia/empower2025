1. Introduction to RDBMS (Relational Database Management System)

What is a Database?

A database is an organized collection of data that can be easily accessed, managed, and updated. A database is used to store data in a structured way, typically using tables, rows, and columns.

What is RDBMS?

RDBMS stands for Relational Database Management System. It is a type of database management system that stores data in the form of related tables. RDBMS is based on E.F. Codd's relational model, where data is organized into one or more tables (or "relations") of columns and rows, with a unique key identifying each row.

Key Features:

Data is stored in tables

Use of SQL to access and manipulate data

Data integrity and constraints

Relationships between tables using foreign keys

Support for transactions (ACID properties)

PostgreSQL

2. Introduction to Normalization

What is Normalization?

Normalization is a process in database design used to eliminate data redundancy and improve data integrity. It involves organizing data into tables in such a way that the results of using the database are always unambiguous and as intended.

Objectives of Normalization:

Eliminate redundant data

Ensure data dependencies make sense

Simplify data structure

Avoid update anomalies (insert, delete, update)

Normal Forms:

1NF (First Normal Form): Remove repeating groups; ensure atomic values

2NF (Second Normal Form): Be in 1NF and remove partial dependencies

3NF (Third Normal Form): Be in 2NF and remove transitive dependencies

BCNF (Boyce-Codd Normal Form): Every determinant must be a candidate key

3. SQL Command Types

SQL (Structured Query Language) is used to interact with RDBMS. SQL commands are divided into several categories:

A. DDL (Data Definition Language)

Used to define and modify the structure of database objects.

Command

Description

CREATE

Create a new table, view, or database

ALTER

Modify an existing table structure

DROP

Delete a table or database permanently

TRUNCATE

Remove all rows from a table quickly

Example:

CREATE TABLE students (
  id INT PRIMARY KEY,
  name VARCHAR(50),
  age INT
);

B. DML (Data Manipulation Language)

Used to manage data within schema objects.

Command

Description

INSERT

Add new rows

UPDATE

Modify existing data

DELETE

Remove rows

Example:

INSERT INTO students (id, name, age) VALUES (1, 'Ravi', 20);
UPDATE students SET age = 21 WHERE id = 1;
DELETE FROM students WHERE id = 1;

C. TCL (Transaction Control Language)

Used to manage transactions.

Command

Description

COMMIT

Save all changes

ROLLBACK

Undo changes since last commit

SAVEPOINT

Create points to rollback to

Example:

BEGIN;
UPDATE students SET age = 25 WHERE id = 2;
SAVEPOINT sp1;
UPDATE students SET name = 'Rahul' WHERE id = 2;
ROLLBACK TO sp1;
COMMIT;

D. DCL (Data Control Language)

Used to control access to data.

Command

Description

GRANT

Give privileges to users

REVOKE

Take back privileges

Example:

GRANT SELECT, INSERT ON students TO 'john';
REVOKE INSERT ON students FROM 'john';

4. SQL Joins

What is a Join?

A join is used in SQL to combine rows from two or more tables, based on a related column between them. Joins help in retrieving data spread across multiple tables.

Types of Joins:

Join Type

Description

INNER JOIN

Returns only matching rows from both tables

LEFT JOIN

Returns all rows from left table and matched rows from right

RIGHT JOIN

Returns all rows from right table and matched rows from left

FULL OUTER JOIN

Returns rows when there is a match in one of the tables

CROSS JOIN

Returns Cartesian product (all combinations)

Example:

SELECT e.emp_name, d.dept_name
FROM employees e
INNER JOIN departments d ON e.dept_id = d.dept_id;
