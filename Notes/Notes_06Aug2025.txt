import java.util.Scanner;

public class App {

	public static void main(String[] args) {
		Scanner sc=new Scanner(System.in);
		String str1=sc.next();
		String str2=sc.next();
		
		char[] carr1 = str1.toCharArray();
		char[] carr2 = str2.toCharArray();
		
		Arrays.sort(carr1);
		Arrays.sort(carr2);
		
		//convert char array into string
		
		String x=new String(carr1);
		String y=new String(carr2);
		
		if(x.equals(y)) {
			System.out.println("Anagrams");
		}else {
			System.out.println("Not anagrams");
		}
		
	}

}

Exceptions
-------------
What are exceptions?
	when we run the program, the program encounters something abnormal, and does not know how to proceed, then it is exception.

exceptions allow us to handle.

What are errors?
	errors are also abnormal events, but we cannot handle them,

Both errors and exceptions are derived from Throwable.


Object
	Throwable
		Error
		Exception



Exception is the super class for all checked exceptions.

RuntimeException is the super class for all unchecked exceptions.

Checked exceptions:
----------------------
are checked by the compiler.
IOException, ParseException, SQLException, InterruptedException


Unchecked exceptions:
--------------------------
are not checked by the compiler. 

ArithmeticException


All exception classes that are derived from RuntimeException are unchecked exceptions. They can be handled or leave as unhandled.


Any unhandled exception will terminate the program.

What is exception handling?
	providing the program, an alternate path to continue, whenever exception occurs.

How to handle exception?
	try block
	catch blocks
	finally block


A try block
	is a guarded section in which any exception occurred are handled by subsequent catch blocks if any.
	A try block can have 0 or more catch blocks
	A try block can have max 1 finally block
	A try block can have catch or finally or both

public class App1 {

	public static void main(String[] args) {
		int i=20;
		int j=0;
		
		
		int k=0;
		
		
		try {
			k=i/j;
		}catch(ArithmeticException ex) {
			System.out.println("Arithmetic exception occurred. Error message is :"+ex.getMessage());
		}
		
		System.out.println("This is last line");
	}

}


now, when you run this code, the exception is handled. Hence the program continues and reach the last line.

public class InvalidEmailException extends RuntimeException
{
	public InvalidEmailException(String message) {
		super(message);
	}
}




public class InvalidPhoneException extends Exception {

	public InvalidPhoneException(String message) {
		super(message);
	}
}





public class Employee {
	private Long id;
	private String name;
	private String email;
	private String phone;
	
	public Employee() {}

	public Employee(Long id, String name, String email, String phone) {
		super();
		this.id = id;
		this.name = name;
		this.email = email;
		this.phone = phone;
	}

	public Long getId() {
		return id;
	}

	public void setId(Long id) {
		this.id = id;
	}

	public String getName() {
		return name;
	}

	public void setName(String name) {
		this.name = name;
	}

	public String getEmail() {
		return email;
	}

	public void setEmail(String email) throws Exception {
		//check the logic
//		email must have @ . etc
//		valid emails:
//			raja@yahoo.com
//			suresh@gmail.com
//
//		invalid emals:
//			raja@.com
//			suresh_gmail.com

		String regex="[A-Za-z]+[A-Za-z0-9]*[@][A-Za-z]+[.][a-z]{2,3}";
		
		if(email.matches(regex)) {
			this.email = email;	
		}else {
			throw new InvalidEmailException("Email address is invalid");
		}
		
		
	}

	public String getPhone() {
		return phone;
	}

	public void setPhone(String phone) throws InvalidPhoneException {
		String regex="[0-9]{10}";
		if(phone.matches(regex))
			this.phone = phone;
		else
			throw new InvalidPhoneException("Phone number is invalid");
	}

	@Override
	public String toString() {
		return "Employee [id=" + id + ", name=" + name + ", email=" + email + ", phone=" + phone + "]";
	}
	
}
