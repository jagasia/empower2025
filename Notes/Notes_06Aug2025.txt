Accept 2 string inputs from user and check if they are "anagrams"

meat

solution1:
------------
if both string lengths are not same, then result is false
sort the characters in alphabetical order of both string
now, if they are same then they are anagrams



import java.util.Arrays;
import java.util.Scanner;

public class App {

	public static void main(String[] args) {
		Scanner sc=new Scanner(System.in);
		String str1=sc.next();
		String str2=sc.next();
		
		char[] carr1 = str1.toCharArray();
		char[] carr2 = str2.toCharArray();
		
		Arrays.sort(carr1);
		Arrays.sort(carr2);
		
		//convert char array into string
		
		String x=new String(carr1);
		String y=new String(carr2);
		
		if(x.equals(y)) {
			System.out.println("Anagrams");
		}else {
			System.out.println("Not anagrams");
		}
		
	}

}

static polymorphism
-----------------------
during compilation itself 2 versions are available means, static polymorphism

method overloading
	is an example for static polymorphism





class Maths
{
	public int sum(int i, int j) {
		return i+j;
	}
	
	public String sum(String s1, String s2) {
		return s1+s2;
	}
}


the above example for method overloading, there is difference in signature.

signature:
	argument/parameters
	number of parameters
	type of parameters
	order or type of parameters



return type is not signature.
	return type may be same or difference that does not decide polymorphism
