class DemoInstanceSupplier implements ServiceInstanceListSupplier {
    private final String serviceId;

    public DemoInstanceSupplier(String serviceId) {
        this.serviceId = serviceId;
    }

    @Override
    public String getServiceId() {
        return serviceId;
    }

    @Override

            .asList(new DefaultServiceInstance(serviceId + "1", serviceId, "localhost", 5001, false),
              new DefaultServiceInstance(serviceId + "2", serviceId, "localhost", 5002, false)));
    }
}

--------------------
The above example shows how to call a webservice 10 times from main method.

Instead, the below code is used to call the webservice from a controller, so that, in browser, if we call multiple times, it serves from difference clone of the webservice.

Also, a simple method of configuring the suppliers in application.yml is also provided at the end.

Right now your code is making WebClient calls directly from the `main` method, but in a real Spring Boot web app you’d usually move this logic into a **Controller** and let Spring handle HTTP requests. You also want **load balancing**, which typically means using **Spring Cloud LoadBalancer** (or Netflix Ribbon in older setups).

Here’s how you can restructure your project:

---

### 1. Add Dependency for Spring Cloud LoadBalancer

In your `pom.xml` (assuming Spring Boot 3.x):

```xml
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-loadbalancer</artifactId>
</dependency>
```

If you’re using Spring Boot 3.x, make sure you also import the Spring Cloud BOM:

```xml
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.springframework.cloud</groupId>
            <artifactId>spring-cloud-dependencies</artifactId>
            <version>2023.0.0</version> <!-- choose latest -->
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
```

---

### 2. Configure a Load-Balanced WebClient Bean

```java
import org.springframework.cloud.client.loadbalancer.LoadBalanced;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.reactive.function.client.WebClient;

@Configuration
public class WebClientConfig {

    @Bean
    @LoadBalanced
    public WebClient.Builder loadBalancedWebClientBuilder() {
        return WebClient.builder();
    }
}
```

The `@LoadBalanced` annotation tells Spring to resolve service names (e.g., `http://my-service`) instead of just plain hostnames.

---

### 3. Create a Controller to Call Your Service

```java
package com.empower.demo.controller;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.reactive.function.client.WebClient;

@RestController
@RequestMapping("/api")
public class DemoController {

    private final WebClient.Builder webClientBuilder;

    @Autowired
    public DemoController(WebClient.Builder webClientBuilder) {
        this.webClientBuilder = webClientBuilder;
    }

    @GetMapping("/call-service")
    public String callService() {
        WebClient client = webClientBuilder.build();

        // Suppose you registered a service "demo-service" in Eureka or config
        String response = client.get()
                .uri("http://demo-service/")  // load-balanced call (instead of localhost:5001)
                .retrieve()
                .bodyToMono(String.class)
                .block();

        return "Response from service: " + response;
    }
}
```

---

### 4. Run Multiple Instances for Load Balancing

* If you use **Eureka/Nacos/Consul** → register multiple instances under the same service name (`demo-service`).
* If you just want a quick round-robin without a registry, define instances in `application.yml`:

```yaml
spring:
  cloud:
    loadbalancer:
      ribbon:
        enabled: false
    discovery:
      client:
        simple:
          instances:
            demo-service:
              - uri: http://localhost:5001
              - uri: http://localhost:5002
              - uri: http://localhost:5003
```

the above in case of application.properties:

spring.cloud.loadbalancer.ribbon.enabled=false

spring.cloud.discovery.client.simple.instances.demo-service[0].uri=http://localhost:5001
spring.cloud.discovery.client.simple.instances.demo-service[1].uri=http://localhost:5002
spring.cloud.discovery.client.simple.instances.demo-service[2].uri=http://localhost:5003


Now each time you hit:
👉 `http://localhost:8080/api/call-service`
it will **round-robin** across 5001, 5002, 5003.

---

✅ Summary:

* Move call logic from `main` → Controller.
* Use `@LoadBalanced WebClient.Builder`.
* Either use Eureka/Consul or static config for load-balanced services.

this demonstrates all of these functions (`getc`, `getchar`, `getch`, `gets`, `putc`, `putchar`, `puts`).

Here’s a clean example:

```c
#include <stdio.h>
#include <conio.h>   // for getch (only on Windows/DOS compilers)

int main() {
    char c;
    char str[50];

    // ---------- getc ----------
    printf("Enter a character (getc): ");
    c = getc(stdin);      // reads from keyboard
    printf("You entered (getc): %c\n", c);
    fflush(stdin);        // clear input buffer (Windows specific)

    // ---------- getchar ----------
    printf("\nEnter another character (getchar): ");
    c = getchar();        // reads one char
    printf("You entered (getchar): %c\n", c);
    fflush(stdin);

    // ---------- getch ----------
    printf("\nPress any key (getch, it won't show on screen): ");
    c = getch();          // does not echo character
    printf("\nYou pressed (getch): %c\n", c);

    // ---------- gets ----------
    printf("\nEnter a string (gets): ");
    gets(str);            // ⚠ unsafe, use only for demo
    printf("You entered (gets): %s\n", str);

    // ---------- putc ----------
    printf("\nUsing putc: ");
    putc('A', stdout);
    putc('\n', stdout);

    // ---------- putchar ----------
    printf("Using putchar: ");
    putchar('B');
    putchar('\n');

    // ---------- puts ----------
    printf("Using puts:\n");
    puts("Hello from puts!");  // prints with newline

    return 0;
}
```

* C is a general-purpose, procedural programming language.

### ✅ Program: Reverse a String with Spaces

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str[200];
    int i, j;
    char temp;

    // Input a full line (with spaces)
    printf("Enter a string: ");
    fgets(str, sizeof(str), stdin);

    // Remove newline character if fgets adds it
    str[strcspn(str, "\n")] = '\0';

    // Get string length
    int len = strlen(str);

    // Swap characters from start and end
    for (i = 0, j = len - 1; i < j; i++, j--) {
        temp = str[i];
        str[i] = str[j];
        str[j] = temp;
    }

    // Print reversed string
    printf("Reversed string: %s\n", str);

    return 0;
}
```

## **Chapter 1: Introduction to HTML**

### Introduction

HTML (**HyperText Markup Language**) is the standard language for creating webpages. It provides the structure of the web, while CSS handles styling and JavaScript adds interactivity.

### Detailed Content

* HTML is made of **elements** → `<tag>content</tag>`
* Tags are mostly paired (`<p></p>`), some are self-closing (`<img />`)
* HTML documents are plain text files with **.html** extension

### Example

```html
<!DOCTYPE html>
<html>
<head>
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>This is my first HTML page.</p>
</body>
</html>
```
