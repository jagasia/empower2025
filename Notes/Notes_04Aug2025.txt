PL/SQL Basics, Cursors, Procedures, Functions, Triggers
----------------------------------------------------------------
PLSQL stands for Procedural Language extension for SQL

what is missing in SQL? that PL/SQL gives us?
	if, switch, while, for
	variables, constants
	user defined functions or procedures
	throwing or catching errors
	

Certainly! Here's a **notepad-friendly comparison** showing what SQL can't do and how PL/SQL handles it — plain, clean, and ready to copy:

---

### 🔹 What SQL **Cannot** Do:

```sql
-- SQL Example (simple query)
SELECT * FROM CUSTOMERS WHERE CITY = 'Chennai';
```

This just fetches data.
But what if you want to process each row, apply conditions, update something, and handle errors?

You **can't** do that with plain SQL.

---

### 🔹 What PL/SQL **Can** Do:

```sql
-- PL/SQL Block Example
DECLARE
   v_name  VARCHAR2(100);
   v_credit NUMBER;
   CURSOR c1 IS
       SELECT NAME, CREDIT_LIMIT FROM CUSTOMERS WHERE CITY = 'Chennai';
BEGIN
   FOR rec IN c1 LOOP
       IF rec.CREDIT_LIMIT > 10000 THEN
           DBMS_OUTPUT.PUT_LINE('VIP Customer: ' || rec.NAME);
           -- You can UPDATE, INSERT, etc.
       ELSE
           DBMS_OUTPUT.PUT_LINE('Regular Customer: ' || rec.NAME);
       END IF;
   END LOOP;
EXCEPTION
   WHEN OTHERS THEN
       DBMS_OUTPUT.PUT_LINE('Something went wrong: ' || SQLERRM);
END;
/
```

---

### 🔹 Summary of What PL/SQL Adds:

* ✅ Variables: `DECLARE v_name VARCHAR2(100);`
* ✅ Loops: `FOR rec IN cursor LOOP ... END LOOP;`
* ✅ Conditions: `IF ... THEN ... ELSE ... END IF;`
* ✅ Exception Handling: `WHEN OTHERS THEN ...`
* ✅ Modularity: `Procedures`, `Functions`, `Packages`

---

```
PL/SQL DATA TYPES

-------------------------------
1. SCALAR DATA TYPES
-------------------------------
-- Single value data types

NUMBER(p,s)       -- Numeric with precision & scale
VARCHAR2(n)       -- Variable-length character
CHAR(n)           -- Fixed-length character
DATE              -- Date and time
BOOLEAN           -- TRUE / FALSE / NULL (only in PL/SQL)

-- Examples:
v_salary   NUMBER(7,2);
v_name     VARCHAR2(50);
v_flag     CHAR(1);
v_dob      DATE;
v_active   BOOLEAN;


-------------------------------
2. COMPOSITE DATA TYPES
-------------------------------
-- Used to group multiple values

RECORD           -- Like a table row
TABLE            -- Indexed collection (associative array)
VARRAY           -- Fixed-size array

-- RECORD Example:
DECLARE
  TYPE emp_rec IS RECORD (
    emp_id    NUMBER,
    emp_name  VARCHAR2(50),
    emp_sal   NUMBER
  );
  v_emp emp_rec;
BEGIN
  v_emp.emp_id := 101;
  v_emp.emp_name := 'Ravi';
  v_emp.emp_sal := 50000;
  DBMS_OUTPUT.PUT_LINE('Name: ' || v_emp.emp_name);
END;
/

-- TABLE Example:
DECLARE
  TYPE name_table IS TABLE OF VARCHAR2(30) INDEX BY BINARY_INTEGER;
  v_names name_table;
BEGIN
  v_names(1) := 'John';
  v_names(2) := 'Alice';
  DBMS_OUTPUT.PUT_LINE(v_names(1));
END;
/

-- VARRAY Example:
DECLARE
  TYPE grade_array IS VARRAY(5) OF NUMBER(3);
  v_grades grade_array := grade_array(85, 90, 75);
BEGIN
  DBMS_OUTPUT.PUT_LINE(v_grades(2));  -- Output: 90
END;
/

-------------------------------
3. LOB AND REFERENCE TYPES
-------------------------------

CLOB         -- Character Large Object
BLOB         -- Binary Large Object
REF CURSOR   -- Pointer to a query result set

-- REF CURSOR Example:
DECLARE
  TYPE emp_cursor IS REF CURSOR;
  c_emp emp_cursor;
BEGIN
  OPEN c_emp FOR SELECT * FROM employees;
  -- Process rows here
  CLOSE c_emp;
END;
/

-------------------------------
4. SUBTYPE (User-defined)
-------------------------------
-- Custom type based on existing data type

SUBTYPE emp_name IS VARCHAR2(100);
v_empname emp_name;

```
